# arunika-media

Penyimpanan video final Arunika (@kabar.arunika) untuk diunggah ke Instagram lewat Buffer (Metricool cadangan).

- `reels/` — file MP4 reel yang siap tayang.
- `tools/` — skrip render reel (align, mix, renderer Polaroid); lihat `tools/README.md`.
- `setup-akun-baru/` — paket pindah ke akun Claude lain (skill, tugas terjadwal, konteks); lihat `setup-akun-baru/README.md`.
